# ADR-0004: Abstention as a legitimate recommendation state — the capture-vs-decision-ready distinction

- **Date**: 2026-09-05 | **Iteration**: 1 | **Status**: Draft | **Deciders**: Jérémie Lumbroso (ratifier — QST below); Pharos 5 (drafting, the convention's tender)

**TL;DR**: External review counsel (GPT 6 Astra Pro, via the founder, grain-of-salt) proposes that an explicit "not decision-ready" be a legitimate Recommendation state — so the form never manufactures a lean where the honest state is generative doubt; drafted here with a contract that keeps abstention from becoming punt-laundering, awaiting the founder's ratification before any page change.

## Context

The Recommendation component, as taught, expects an attributed lean on
every question. But questions arrive in two states the convention does
not currently distinguish at the QST grain: **captured** (the question
is real and staked, but the evidence to lean on is not yet in anyone's
hands) and **decision-ready**. Forcing a lean at capture time produces
either a manufactured lean — performative confidence's cousin, wearing
the R slot — or, worse, suppresses the question's filing entirely,
which suppresses exactly the generative doubt the practice exists to
harvest. The house already embodies this distinction one level up
(seeds capture; decision records decide); the proposal makes it
explicit one level down.

## Questions

### QST-ABSTENTION: May a Recommendation legitimately be "not decision-ready yet" — and under what contract?

- Status: unanswered
- Why asking: It changes the R component's contract on the public page; the convention's tender does not ratify convention changes alone.
- Need: yes/no on the state; the contract below is adjustable in any shape

**Recommendation**: (by Fable 5, Pharos)
**Yes — with a three-part contract that keeps abstention load-bearing.** An abstention is not an empty slot; it carries: (1) *why* the question is not decision-ready — the specific missing evidence, named; (2) *the ripening condition* — what arriving evidence or event would make it decision-ready (a falsifier's sibling, pointed at the question's readiness instead of a recommendation's truth); (3) attribution and date, like any lean. Because the alternative is worse on the record's own terms: A manufactured lean corrupts the calibration the Confidence component exists to protect, and a suppressed question is invisible to every future auditor. If wrong: Abstention drifts into punt-laundering — the record starts showing abstentions on questions whose threads already held sufficient evidence, or abstention becomes the path of least resistance on exactly the core questions the house's own law says must never be punted — in which case the contract tightens (abstention requires naming the missing evidence *specifically enough that a peer can go fetch it*), and this ADR gains the iteration saying so.

## Proposed page wording (applies only on ratification; the page is untouched until then)

One sentence inside the Recommendation component's definition:

> An honest "not decision-ready — here is what's missing, and what would
> ripen it" is a legitimate recommendation; a manufactured lean is
> performative confidence wearing the slot.
